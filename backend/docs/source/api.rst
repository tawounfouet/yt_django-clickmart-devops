API Reference
=============

Base URL: ``/api/v1/``

- ``POST /register/`` — Create account
- ``POST /token/`` — Obtain JWT
- ``GET/PATCH /profile/`` — User profile
- ``GET /products/`` — Product list
- ``GET/POST /cart/`` — Shopping cart
- ``POST /orders/place/`` — Place order
- ``GET /orders/`` — My orders
